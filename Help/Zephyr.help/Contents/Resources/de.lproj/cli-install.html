Wenn sich das Befehlszeilenprogramm nicht installieren lässt

Das Programm zu installieren bedeutet, einen Link unter /usr/local/bin/zephyr anzulegen. Das Installationspaket erledigt das für dich; bei einer Kopie, die du aus einem Disk-Image herausgezogen hast, genügt dafür ein Befehl im Terminal. So kann dabei etwas schiefgehen.

Wenn du erwartet hast, dass Zephyr es für dich installiert

Das Installationspaket tut das während der Installation, es sei denn, du hast im Bereich „Anpassen“ das Häkchen bei „Befehlszeilenprogramm“ entfernt. macOS hält eine laufende App jedoch aus /usr/local/bin heraus. Ein Zephyr, das du aus einem Disk-Image herausgezogen oder ohne diese Auswahl installiert hast, kann dir deshalb nur den Befehl zeigen, den du dann einmal selbst ausführst.

  1. Scrolle in den Einstellungen von Zephyr zu „Befehlszeilenprogramm“ und klicke auf „Kopieren“.

  2. Füge den Befehl im Terminal ein und drücke die Eingabetaste (Return).

Zephyr muss dafür nicht geöffnet sein, und du musst das nur einmal pro Kopie der App tun. Wenn im Bereich Installiert in /usr/local/bin steht und kein Befehl angeboten wird, ist nichts zu tun.

Wenn das Terminal den Link nicht anlegt

Der Befehl beginnt mit sudo, und dafür gibt es zwei Voraussetzungen.

  • Es wird ein Passwort abgefragt. Gib dein Anmeldepasswort ein — beim Tippen erscheint nichts, das ist normal — und drücke die Eingabetaste.

  • Dein Account muss ein Administrator sein. Ein Standard-Account darf dort nichts schreiben. Prüfe das in Systemeinstellungen > Benutzer:innen & Gruppen oder frage die Person, die den Mac verwaltet.

Wenn das Terminal no such file or directory meldet, fehlt der Ordner selbst. Führe zuerst sudo mkdir -p /usr/local/bin aus und danach den Befehl, den Zephyr dir angezeigt hat.

Wenn Zephyr meldet, dass das Programm nicht enthalten ist

Zwei Versionen melden das, aus verschiedenen Gründen.

  • Die Version aus dem App Store. Der App Store erlaubt es einer App nicht, etwas in deinem PATH zu installieren. Deshalb wird sie ohne das Programm ausgeliefert, und der Bereich weist darauf hin. Die Version zum Herunterladen findest du unter zephyrmac.app — siehe Zwischen den beiden Versionen von Zephyr wählen.

  • Eine Version, die es schlicht nicht enthält. Lade Zephyr erneut von der Website des Projekts herunter.

Wenn die Shell zephyr nicht findet

Der Link ist installiert, aber deine Shell sucht nicht an dieser Stelle.

  1. Öffne ein neues Terminalfenster. Eine bereits laufende Shell erkennt einen neuen Befehl nie.

  2. Führe echo $PATH aus und prüfe, ob /usr/local/bin darin enthalten ist.

  3. Wenn nicht, ergänze es in der Startdatei deiner Shell — ~/.zshrc für zsh.

Hinweis: Wenn du Zephyr.app an einen anderen Ort verschiebst, zeigt der Link weiterhin auf den bisherigen Ort. Kopiere den Befehl erneut aus den Einstellungen von Zephyr und führe ihn aus: Er nennt den neuen Ort und ersetzt den alten Link.

Wenn sich das Programm nicht authentifizieren kann

zephyr verwaltet seine Zugangsdaten getrennt von der App. Ein Account, den die App verknüpft hat, kann vom Programm daher aufgelistet, aber nicht verwendet werden. Führe einmal zephyr auth link für das Programm aus. Der Exit-Code 69 bedeutet, dass überhaupt kein Account verknüpft ist. So kann ein Skript das von einem echten Fehler unterscheiden.
