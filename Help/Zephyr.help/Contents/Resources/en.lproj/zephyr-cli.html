Install the zephyr command-line tool

The downloadable version of Zephyr carries a command-line tool. It reads the same accounts and the same index the app does, so it can list a folder nothing has ever downloaded without touching the network.

Install it

If you installed Zephyr with the installer package and left Command-Line Tool switched on, the tool is already on your PATH — the installer links it while it runs. Open a Terminal window and run zephyr --help. Zephyr’s settings say so too: Command-Line Tool reads Installed in /usr/local/bin.

If you turned that choice off in the installer, or installed Zephyr by dragging it out of a disk image, nothing has made the link. macOS doesn’t let Zephyr put anything on your PATH itself, so it shows you the command that does.

  1. Click Zephyr in the menu bar, then click Settings…

  2. Scroll to Command-Line Tool, then click Copy.

  3. In Terminal, paste the command and press Return.

    It links the tool into /usr/local/bin. sudo asks for your password, and the account you are signed in to has to be an administrator.

  4. Open a new Terminal window and run zephyr --help.

Note: The App Store version doesn’t ship the tool, and the pane says so instead. The App Store doesn’t allow an app to put anything on your PATH. To use the tool, install the downloadable version from riscfuture.github.io/Zephyr — see Choose between the two versions of Zephyr, which covers switching without losing your Finder location.

Link an account for the tool

The tool keeps its credentials in your login keychain, separately from the app’s. It can see an account the app linked, but it can’t act as one it didn’t link itself.

  1. In Terminal, run zephyr auth link

    It prints an authorization URL and opens it in your browser.

  2. Approve access on Dropbox’s page, then copy the authorization code Dropbox shows you.

  3. Switch back to Terminal, paste the code after Enter the authorization code shown by Dropbox:, and press Return.

zephyr auth list shows which accounts the tool can authenticate as.

What it can do

zephyr --help lists everything. In brief: ls, get, put, rm, mkdir, and mv for files; revs, restore, and diff for a file’s earlier versions; sharelink for shared links; find to look for an item by name anywhere in your Dropbox, including files that are not on this Mac; and status, filestatus, and history for what Zephyr knows.

Four more are the Terminal counterparts of settings you would otherwise open the app for: bandwidth-limit sets the upload, download, and metered rates; ignored lists what you have taken out of syncing; notify snoozes notifications; and rebuild-index starts an account’s index over. log reads Zephyr’s recent log, and gui opens the app.

Commands act on the only linked account unless you pass --account. bandwidth-limit, notify, log, and gui take no --account at all, because none of them belongs to one account. Twelve commands also take --json.

Note: watch is a diagnostic command rather than a way to keep an account current. Zephyr itself is what watches Dropbox for changes — see Keep Zephyr running in the background.

Add shell completion

zephyr --generate-completion-script writes a completion script for zsh, bash, or fish. For zsh:

  1. Run mkdir -p ~/.zsh/completions

  2. Run zephyr --generate-completion-script zsh > ~/.zsh/completions/_zephyr

  3. Add fpath=(~/.zsh/completions $fpath) to ~/.zshrc, above the compinit line, then open a new Terminal window.

Dropbox paths complete out of Zephyr’s index, one folder per Tab, so a folder nothing has downloaded completes exactly like one that’s already here.
