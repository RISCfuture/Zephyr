Use Zephyr in a shortcut

Zephyr adds actions to the Shortcuts app, so you can pause syncing, send a file to Dropbox, or get a share link as a step in something larger. Both versions of Zephyr have them.

Add a Zephyr action to a shortcut

  1. Open the Shortcuts app, then click the add button in the toolbar to make a new shortcut.

  2. In the action list on the right, type Zephyr in the search field.

  3. Double-click the action you want. It appears in the shortcut.

  4. Fill in whatever the action asks for — a file, a folder, an account — then click the run button to try it.

These are the actions Zephyr adds:

  • Pause or Resume Syncing stops or starts syncing for every account, the same as the menu-bar panel’s Pause Syncing.

  • Snooze Zephyr Notifications holds every notification for 30 minutes, an hour, or eight hours, or ends a snooze early. Syncing carries on.

  • Get Sync Status answers with how many files and folders Zephyr has indexed and how many items couldn’t sync.

  • Upload to Dropbox sends a file to a folder you pick.

  • Get Dropbox Share Link answers with a link to a file or folder, making one if it doesn’t already have one. Follow it with Copy to Clipboard to put the link there.

  • Restore Dropbox File puts a file back to one of the versions Dropbox kept. It asks before it does.

The file and folder fields search Zephyr’s index rather than your disk, so a folder nothing has ever downloaded is offered exactly like one that’s already here.

Run an action without building a shortcut

Pause Syncing, Snooze Notifications, and Sync Status are also offered on their own.

  1. Press Command-Space to open Spotlight.

  2. Type the name of the action, such as Pause Syncing.

  3. Press Return.

You can ask Siri for them too, by saying something like “Pause syncing in Zephyr.” Zephyr doesn’t need to be open: it starts in the background, does the work, and doesn’t come to the front.

If an action says no account is linked

Shortcuts act as the accounts you linked in the Zephyr app. The zephyr command-line tool keeps its own separate credentials, so an account you linked only by running zephyr auth link is not one a shortcut can use.

  1. Click Zephyr in the menu bar, then click Manage Accounts…

  2. Click Link Dropbox Account… in the toolbar, and link the account there.

When you have more than one account linked, actions that reach into a Dropbox ask which one. With only one, they use it without asking.
