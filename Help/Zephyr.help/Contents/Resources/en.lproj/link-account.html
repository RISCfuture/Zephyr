Link your Dropbox account

Zephyr shows a Dropbox account’s files in Finder once you link the account. Linking opens Dropbox’s own page, where you approve the access Zephyr asks for; approving sends you straight back.

Before you begin

  • Install Zephyr rather than dragging it out of a downloaded disk image. Linking works wherever Zephyr is, but macOS runs a downloaded app from a temporary copy of its own and won’t put a linked account in Finder for one. See If your Dropbox doesn’t appear in Finder.

  • Have your Dropbox password to hand. You approve access on Dropbox’s own website, not in Zephyr — Zephyr never sees your password.

Link an account

  1. Click Zephyr in the menu bar, then click Manage Accounts…

  2. Click Link Dropbox Account… (+) in the toolbar.

    You can also choose Account ▸ Link Dropbox Account…, or press ⌘L.

  3. Click Connect Dropbox Account…

    Dropbox’s authorization page opens in a window of its own. Sign in if you aren’t already, then approve the access Zephyr asks for. The window closes itself once you have.

The account appears in the list, and Zephyr starts building an index of what’s in it. The first index of a large Dropbox takes a while; you don’t have to wait for it to finish before using your files.

Note: Closing the authorization window without approving cancels the link and changes nothing. Click Connect Dropbox Account… again to start over.

If Dropbox can’t send you back to Zephyr

Dropbox can also hand you a code to carry back yourself. Use this if the authorization window won’t open, or if Dropbox reports a problem returning to Zephyr.

  1. In the link window, click Enter a code instead.

  2. Click Open Dropbox in Browser, and approve access there as above.

  3. Copy the authorization code Dropbox shows you, switch back to Zephyr, and paste it into the Authorization code field.

    Note: If you closed the browser page or the code expired, click Open Dropbox in Browser again to get a fresh one.

  4. Click Link.

Turn Zephyr on in Finder

Linking an account isn’t enough on its own. macOS asks you, not Zephyr, whether a file provider may show files in Finder, and it only offers the switch once an account is linked. See Turn on Zephyr in Finder.

Open an account, or copy its address

  1. In the Zephyr window, Control-click the account.

  2. Choose Open in Finder to reveal that account’s files, or Copy Email Address to put the address on the clipboard.

Unlink an account

  1. In the Zephyr window, Control-click the account.

  2. Choose Unlink…, then confirm.

Unlinking revokes Zephyr’s access to the account and removes it from Finder. Nothing in your Dropbox is deleted.

Note: The zephyr command-line tool keeps its credentials separately from the app, so it can list an account the app linked but can’t act as one. Run zephyr auth link once for the tool, even if the app is already set up. See Install the zephyr command-line tool.
