If your Dropbox doesn’t appear in Finder

An account can be linked, indexed, and syncing and still not appear in Finder. These are the reasons, in the order worth checking.

Check that Zephyr is switched on

macOS asks you, not Zephyr, whether a file provider may show files. This is much the most common cause.

  1. Choose Apple menu > System Settings, click General, click Login Items & Extensions, then click File Providers.

    Open File Providers for me

  2. Turn on Zephyr.

If Zephyr isn’t listed there at all, no account is linked yet — there is nothing for macOS to offer. See Link your Dropbox account.

Check that Finder is showing cloud locations

Finder keeps every cloud location — Zephyr’s, and any other sync app’s — behind a single setting, and hides them all while it is switched off. An account can be linked, switched on, indexed, and syncing and still have no row in the sidebar.

  1. Click the Finder icon in the Dock, then choose Finder > Settings.

  2. Click Sidebar.

  3. Under Locations, select Cloud Storage.

Your Dropbox appears straight away — there is nothing to restart, and nothing in Zephyr to change. If you use another sync app, it appears at the same moment, which is the clearest sign this was the cause.

Note: This setting belongs to Finder rather than to any app whose files it shows, so Zephyr can neither read it nor switch it on for you — and can’t warn you when it is what is wrong. It costs nothing to check first.

If you would rather leave the setting alone, put your Dropbox in Favorites instead: open it in Finder, then drag the folder’s icon from the top of the window into the Favorites section of the sidebar. A favorite doesn’t depend on Cloud Storage. See Where your files live.

Check that Zephyr isn’t running from a copy

An app you downloaded carries a flag saying so, and macOS runs a flagged app out of a temporary copy of its own rather than from the folder you put it in. It will not register a file provider for one, so Zephyr never reaches the File Providers list at all.

Zephyr can’t clear the flag itself, and moving the app in the Finder doesn’t clear it either. Installing it does.

  1. Quit Zephyr.

  2. Download the installer package — the file ending in .pkg — from riscfuture.github.io/Zephyr.

  3. Open it and follow the installer. It writes Zephyr into your Applications folder without the flag, replacing the copy you have.

  4. Open Zephyr again.

The flag is set once, by the Finder, when you drag an app out of a downloaded disk image. It is never set on anything an installer writes, so this is a one-time fix — not something to repeat after an update.

Note: If you would rather not download Zephyr again, the flag can be cleared by hand instead. Quit Zephyr, run xattr -dr com.apple.quarantine "/Applications/Zephyr.app" in Terminal — naming wherever you keep Zephyr, if that isn’t your Applications folder — and open it again.

Check that only one version is installed

The App Store and downloadable versions are the same app as far as macOS is concerned, and with both installed an older one can end up serving your files. Keep one. See Choose between the two versions of Zephyr.

Note: To switch versions, install the new copy and open it, confirm your account still appears in Finder, and only then delete the old one. Deleting first can take the Finder location with it.

Start the Finder location over

A Finder location outlives the app that registered it, and one registered by an older build can keep settings you can’t talk it out of. This clears them.

  1. Quit Zephyr.

  2. In Terminal, run:

    /Applications/Zephyr.app/Contents/MacOS/Zephyr --reset-domains

  3. Open Zephyr again.

Zephyr registers your accounts from scratch and each one re-indexes. Nothing in your Dropbox is touched, and no download you already have is lost — but you will have to switch Zephyr on under File Providers again.
