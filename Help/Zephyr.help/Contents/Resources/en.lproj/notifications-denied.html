If you don’t see Zephyr’s notifications

Three separate things can silence Zephyr, and they’re worth ruling out in this order.

Check that macOS allows them

  1. Choose Apple menu > System Settings, then click Notifications.

    Open Notifications for me

  2. Find Zephyr, then turn on Allow notifications.

If you refused Zephyr’s first prompt, this is the only place to change that answer — macOS won’t show the prompt a second time, and Zephyr can’t make it.

Check Zephyr’s own level

  1. Click Zephyr in the menu bar, then click Settings…

  2. Under Notifications, check Notify about.

Set to Errors only, an ordinary file change won’t notify. Set to None, nothing will. See Choose which notifications Zephyr shows.

Check for a snooze

Click Zephyr in the menu bar. If a snooze is running, the row says Snoozed until and the time it ends. Click Resume to end it now.

Nothing is lost to a snooze: what it silenced notifies once it ends.

Note: A macOS Focus can hold notifications back from every app at once. Check the Focus in Control Center before concluding that Zephyr is at fault.
