Collect a diagnostic report

If something is wrong and the fix isn’t obvious, a diagnostic report is what turns “it doesn’t work” into something that can be looked into.

Collect a report

  1. Click Zephyr in the menu bar, then click Settings…

  2. Scroll to Troubleshooting, then click Collect… beside Diagnostics.

  3. When it finishes, Finder opens with the report selected.

Note: The report names files from your Dropbox. Read it before you send it to anyone, and remove anything you’d rather not share.

What’s in it

  • Zephyr’s version, your macOS version, and when the report was collected.

  • Whether syncing is paused, which notification level is set, all four transfer limits, and anything macOS is withholding.

  • Each linked account: its identifier, which kind of Dropbox root it has, when you linked it, the state of its Finder location, and its file and folder counts.

  • Every item that couldn’t sync, by its full Dropbox path, with the reason.

  • Every item you have taken out of syncing, by its full Dropbox path.

  • Zephyr’s recent log from the process that collected the report.

It does not contain the contents of any file, and it does not contain your Dropbox credentials.

Capture more detail

Zephyr deliberately keeps your file names out of the system log, so a log captured beside the report describes what happened without saying which file it happened to.

The report itself does name them, which is why it asks you to read it before sending it. There is no longer a Terminal command that unredacts the log: macOS dropped the setting, and revealing private data now takes a configuration profile installed across the whole Mac.

Send it in

Zephyr’s issue tracker is where reports go. Click Zephyr in the menu bar, click Settings…, then click Report an Issue under About.
