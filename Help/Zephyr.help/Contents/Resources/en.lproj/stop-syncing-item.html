Stop syncing a file or folder

Some things belong on this Mac but not in your Dropbox — a build folder, a scratch directory, anything large that would only ever be uploaded once and never read again. Zephyr can take an item out of Dropbox and leave it here.

Stop syncing an item

  1. In Finder, Control-click the file or folder.

  2. Choose Delete from Dropbox, Keep on This Mac.

The item is deleted from your Dropbox and stays on this Mac, marked with a badge reading Not on Dropbox — this Mac only. Nothing you do to it from now on is uploaded, and it won’t appear on your other devices.

Note: The command does what it says: the copy in Dropbox is deleted. If the item has never been downloaded to this Mac there is nothing here to keep, so download it first — open it, or open the folder — before you use this.

Why an item might already be excluded

Zephyr never syncs a small set of names macOS and other tools scatter about, such as .DS_Store. Those aren’t listed as excluded items; they simply never sync.

Zephyr also honours the marker the official Dropbox client uses, so an item excluded there is excluded here.
