Choose which notifications Zephyr shows

Zephyr can tell you about every file that changes, or only about things that went wrong, or nothing at all.

Set the level

  1. Click Zephyr in the menu bar, then click Settings…

  2. Under Notifications, choose from the Notify about menu.

Level

What you hear about

All file changes

Every file added, changed, or removed, as well as everything below. Useful on a shared folder you’re watching; noisy on a busy account.

Sync issues

Items that couldn’t sync, and errors.

Errors only

Problems with the account itself — access revoked, Dropbox unreachable.

None

Nothing. Zephyr still records what went wrong; you just have to look. See If a file won’t sync.

Silence Zephyr for a while

  1. Click Zephyr in the menu bar.

  2. Click Snooze Notifications, then choose 30 min, 1 hr, or 8 hr.

  3. To end a snooze early, click Zephyr in the menu bar and click Resume.

A snooze holds everything, sync errors included, and nothing is thrown away: whatever it silenced notifies once the snooze ends. Zephyr’s settings show how long is left.

Note: If you’ve set a level but see nothing at all, macOS may be blocking Zephyr’s notifications — see If you don’t see Zephyr’s notifications.
