If you deleted something you needed

Deleting an item in your Dropbox deletes it on Dropbox and on every device signed in to the account, and Zephyr keeps no trash of its own to take it back out of.

What a delete does

  • The item goes from Dropbox as well as from this Mac, within seconds, and from your other devices as they catch up.

  • Your Dropbox in Finder has no Trash of its own. Dropbox offers Zephyr no way to keep one, so Zephyr doesn’t pretend to.

  • Nothing appears in Sync Issues. A delete that reached Dropbox worked; it is only the wrong thing to have wanted.

Zephyr has no way to bring a deleted item back. Whether Dropbox itself still holds a copy is a question for Dropbox, on Dropbox’s own website.

If the file is still there but wrong

A file that was written over rather than deleted is a different matter: Dropbox kept what it said before, and you can put an earlier version back without leaving Finder.

  1. In Finder, Control-click the file.

  2. Choose Show Previous Versions…

See Go back to an earlier version of a file.

Find out what was deleted, and when

Zephyr keeps a week of what it synced, which is enough to say what went and in which direction — it isn’t a copy of anything, but it will tell you whether the delete came from this Mac or arrived from somewhere else.

  1. In Terminal, run zephyr history

  2. Read the CHANGE column for removed, and the DIRECTION column for up — this Mac sent it — or down, meaning another device did.

The command comes with the downloadable version of Zephyr — see Install the zephyr command-line tool.

Take something out of Dropbox without deleting it

If what you wanted was to stop something syncing rather than to lose it, there is a command that keeps your copy: Delete from Dropbox, Keep on This Mac downloads the item first and only then removes Dropbox’s copy. See Stop syncing a file or folder.
