Open a file, and free up space again

You don’t download a file in Zephyr — you open it, and Finder fetches it. When you’re finished you can give the space back without taking the file out of your Dropbox.

Open a file

  1. In Finder, find the file in your Dropbox.

  2. Double-click it.

    Finder downloads it and hands it to the app that opens it. A large file over a slow connection can take a moment; Finder shows the progress on the file’s icon.

Zephyr checks every download against the content hash Dropbox recorded for it, so a file that arrived damaged is refused rather than opened.

Free up the space again

  1. Control-click the file in Finder.

  2. Choose Remove Download.

The file stays in your Dropbox and stays listed in Finder. Only the copy on this Mac goes, and opening the file again brings it back.

Note: macOS may also free up downloads on its own when your disk fills. That isn’t Zephyr deleting anything, and nothing leaves your Dropbox.

Edit, move, and delete

Everything you do to a file in Finder reaches Dropbox: saving an edit uploads it, moving or renaming it moves or renames it in Dropbox, and dragging it to the Trash deletes it there too. Zephyr syncs both ways; there is nothing to press.

A delete reaches Dropbox and every device signed in to the account, and there is no Dropbox trash to take it back out of — see If you deleted something you needed.

To take an item out of Dropbox but keep it here, use Stop syncing a file or folder instead of deleting it.
