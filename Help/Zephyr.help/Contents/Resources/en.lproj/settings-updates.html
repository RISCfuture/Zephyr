Check for Zephyr updates

How Zephyr updates depends on which version you have. Both show the version they’re running in the same place.

See your version

  1. Click Zephyr in the menu bar, then click Settings…

  2. Scroll to Updates and read Version.

The number can be selected and copied, which is what a bug report wants.

The downloadable version

It checks for new releases itself.

  1. Choose how often from the Check automatically menu.

  2. To check now, click Check Now.

    Last checked says when the last check ran.

You can also choose Check for Updates… from Zephyr’s application menu while one of its windows is open.

The App Store version

The App Store keeps it current, so there is nothing to check and no controls here — the section says so instead.

If you would rather Zephyr checked for itself, the downloadable version is published at riscfuture.github.io/Zephyr. See Choose between the two versions of Zephyr, which covers switching without losing your Finder location.

Note: Install only one version at a time. Both are the same app to macOS, and having both installed can leave an older one serving your files. See Choose between the two versions of Zephyr.
