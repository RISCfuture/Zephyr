Descubrir en qué se basa Zephyr

Zephyr es de código abierto bajo la MIT License. Los componentes en los que se basa tienen sus propios términos, y aquí se nombran los que exigen una mención.

Trabajos previos

Zephyr es una reimplementación de Maestral, de Sam Schott, el cliente de Dropbox de código abierto escrito en Python — MIT. No se usa ni se distribuye código de Maestral. Lo que Zephyr hereda es el criterio de Maestral: el conjunto de nombres de archivo que nunca se sincronizan, la duración del historial que se conserva y la forma de tratar el flujo de cambios. Es la razón de que este proyecto fuera viable.

Menciones de Apache-2.0

La Apache License 2.0 impone una obligación de mención al distribuir binarios, por lo que se señalan aparte:

  • swift-argument-parser — Copyright the Swift project authors. Apache-2.0 with the Swift Runtime Library Exception.

  • swift-log — Copyright 2018–2019 The SwiftLog Project. Apache-2.0, sin excepción. Contiene una derivación de la implementación de bloqueos de SwiftNIO, también bajo Apache-2.0.

El texto completo de la Apache License, Version 2.0 está en apache.org/licenses/LICENSE-2.0.

Paquetes de Swift

Las dependencias directas de Zephyr:

  • GRDB.swift, de Gwendal Roué — MIT. La capa de SQLite bajo el índice de sincronización de cada cuenta.

  • Semaphore, de Gwendal Roué — MIT.

  • swift-argument-parser — Apache-2.0. Detrás de los argumentos de la herramienta de línea de comandos zephyr.

  • GitHubUpdateChecker — MIT.

  • sentry-cocoa — MIT. Informes de fallos.

Y las que se incorporan a través de ellas: swift-markdown-ui y NetworkImage, de Guillermo Gonzalez — MIT.
