Utiliser plusieurs comptes Dropbox

Zephyr synchronise en même temps tous les comptes que vous associez. Chacun a sa propre place dans la barre latérale du Finder et son propre index.

Associer un autre compte

Associer un deuxième compte se fait exactement comme le premier — consultez Associer votre compte Dropbox. Vous vous connectez à Dropbox dans votre navigateur une fois par compte.

Après l’association, activez Zephyr pour le nouveau compte sous Fournisseurs de fichiers si macOS vous le demande ; consultez Activer Zephyr dans le Finder.

Les distinguer

  • Dans le Finder : chaque compte apparaît dans la barre latérale sous le nom Zephyr suivi de l’adresse e-mail du compte ; c’est donc l’adresse qui permet de distinguer deux comptes.

  • Dans la barre des menus : le panneau répertorie chaque compte avec sa propre ligne d’état et ses compteurs. Un clic sur l’un d’eux ouvre ce compte dans le Finder.

  • Dans les réglages : Éléments non synchronisés s’applique à chaque compte et nomme chacun au-dessus de ses propres commandes lorsque plusieurs comptes sont associés. Ce n’est pas le cas de Débit : les limites de transfert appartiennent à ce Mac, et tous les comptes les partagent.

L’icône de la barre des menus et la ligne qui l’accompagne reflètent l’ensemble de ce Mac : un seul compte en cours d’envoi s’affiche donc comme une activité, même si les autres sont inactifs. Ce qui arrête tous les comptes à la fois, comme un réseau facturé à l’usage, n’est signalé qu’une fois en haut du panneau plutôt que sous chaque compte.

Utiliser l’outil en ligne de commande

zephyr agit sur l’unique compte associé, sauf si vous passez --account ; lorsque plusieurs comptes sont associés, vous devrez donc en désigner un. zephyr auth list affiche les identifiants à utiliser, et la complétion du shell les propose.
