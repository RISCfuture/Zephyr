Si vous avez supprimé un élément dont vous aviez besoin

Supprimer un élément de votre Dropbox le supprime sur Dropbox et sur tous les appareils connectés au compte, et Zephyr ne tient pas de corbeille dans laquelle le récupérer.

Ce que fait une suppression

  • L’élément disparaît de Dropbox comme de ce Mac, en quelques secondes, puis de vos autres appareils à mesure qu’ils se mettent à jour.

  • Votre Dropbox dans le Finder n’a pas de Corbeille propre. Dropbox ne permet pas à Zephyr d’en conserver une ; Zephyr ne fait donc pas semblant.

  • Rien n’apparaît dans Problèmes de synchronisation. Une suppression qui a atteint Dropbox a fonctionné ; c’est seulement qu’elle n’était pas souhaitée.

Zephyr ne peut pas rétablir un élément supprimé. Savoir si Dropbox en détient encore une copie est une question qui relève de Dropbox, sur le site web de Dropbox.

Si le fichier est toujours là, mais incorrect

Un fichier écrasé plutôt que supprimé est un autre cas : Dropbox a conservé son contenu précédent, et vous pouvez rétablir une version antérieure sans quitter le Finder.

  1. Dans le Finder, cliquez sur le fichier en maintenant la touche Contrôle enfoncée.

  2. Choisissez Show Previous Versions…

Consultez Revenir à une version antérieure d’un fichier.

Savoir ce qui a été supprimé, et quand

Zephyr conserve une semaine de ce qu’il a synchronisé, ce qui suffit pour dire ce qui a disparu et dans quel sens : ce n’est la copie de rien, mais cela vous indique si la suppression vient de ce Mac ou d’ailleurs.

  1. Dans Terminal, exécutez zephyr history

  2. Repérez removed dans la colonne CHANGE, puis up dans la colonne DIRECTION (ce Mac l’a envoyé) ou down (un autre appareil l’a fait).

La commande est fournie avec la version téléchargeable de Zephyr ; consultez Installer l’outil en ligne de commande zephyr.

Retirer un élément de Dropbox sans le supprimer

Si vous vouliez arrêter la synchronisation d’un élément plutôt que le perdre, une commande conserve votre copie : Delete from Dropbox, Keep on This Mac télécharge d’abord l’élément, puis seulement supprime la copie de Dropbox. Consultez Arrêter la synchronisation d’un fichier ou d’un dossier.
