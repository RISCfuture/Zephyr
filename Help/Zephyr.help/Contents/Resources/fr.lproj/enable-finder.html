Activer Zephyr dans le Finder

C’est macOS, et non Zephyr, qui vous demande si une app peut placer des fichiers dans le Finder. Tant que vous n’avez pas activé Zephyr sous Fournisseurs de fichiers, un compte associé se synchronise mais n’apparaît jamais.

Avant de commencer

  • Installez Zephyr au lieu de le glisser hors d’une image disque téléchargée. macOS exécute une app téléchargée depuis une copie temporaire qui lui est propre et n’enregistre pas de fournisseur de fichiers pour une telle copie : Zephyr n’atteint donc jamais la liste Fournisseurs de fichiers. Consultez Si votre Dropbox n’apparaît pas dans le Finder.

  • Associez d’abord un compte Dropbox. Zephyr n’apparaît dans la liste Fournisseurs de fichiers que lorsqu’il y a un compte à afficher : le réglage que vous cherchez n’y figure donc pas encore si vous n’en avez pas associé. Consultez Associer votre compte Dropbox.

Activer Zephyr

  1. Choisissez le menu Pomme > Réglages Système, cliquez sur Général dans la barre latérale, cliquez sur Ouverture et extensions, puis sur Fournisseurs de fichiers.

    Ouvrir « Fournisseurs de fichiers » pour moi

  2. Activez Zephyr.

  3. Ouvrez une nouvelle fenêtre du Finder. Votre Dropbox apparaît dans la barre latérale sous Emplacements. S’il n’y figure pas, le Finder masque peut-être les emplacements cloud — consultez Si votre Dropbox n’apparaît pas dans le Finder.

Remarque : Zephyr surveille ce réglage et cesse de vous le demander dès que vous l’avez activé. Si l’avertissement s’affiche encore, cliquez sur l’icône de Zephyr dans la barre des menus — la vérification est relancée à chaque ouverture du panneau.

Laisser Zephyr s’exécuter

C’est Zephyr qui surveille les modifications de Dropbox : le Finder n’est donc informé d’une modification faite sur un autre appareil que si Zephyr est en cours d’exécution. L’ouvrir à l’ouverture de session garantit cela sans que vous ayez à y penser — consultez Laisser Zephyr s’exécuter en arrière-plan.
