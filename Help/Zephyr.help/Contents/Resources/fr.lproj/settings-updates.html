Rechercher les mises à jour de Zephyr

La façon dont Zephyr se met à jour dépend de la version que vous avez. Les deux affichent la version utilisée au même endroit.

Voir votre version

  1. Cliquez sur Zephyr dans la barre des menus, puis sur Réglages…

  2. Faites défiler jusqu’à Mises à jour et lisez Version.

Le numéro peut être sélectionné et copié, ce qui est utile pour un rapport de bug.

La version téléchargeable

Elle recherche elle-même les nouvelles versions.

  1. Choisissez la fréquence dans le menu Vérifier automatiquement.

  2. Pour vérifier maintenant, cliquez sur Vérifier maintenant.

    Dernière vérification indique quand la dernière vérification a eu lieu.

Vous pouvez aussi choisir Rechercher des mises à jour… dans le menu de l’app Zephyr tant que l’une de ses fenêtres est ouverte.

La version App Store

L’App Store la maintient à jour : il n’y a donc rien à vérifier et aucune commande ici — la section l’indique à la place.

Si vous préférez que Zephyr recherche lui-même les mises à jour, la version téléchargeable est publiée sur zephyrmac.app. Consultez Choisir entre les deux versions de Zephyr, qui explique comment passer de l’une à l’autre sans perdre votre emplacement dans le Finder.

Remarque : N’installez qu’une seule version à la fois. Pour macOS, les deux sont la même app, et les avoir toutes les deux installées peut conduire une version plus ancienne à servir vos fichiers. Consultez Choisir entre les deux versions de Zephyr.
