Si l’outil en ligne de commande ne s’installe pas

Installer l’outil consiste à créer un lien à l’emplacement /usr/local/bin/zephyr. Le paquet d’installation le crée pour vous ; une copie glissée depuis une image disque demande une commande dans le Terminal. Voici les cas où cela se passe mal.

Si vous pensiez que Zephyr l’installerait pour vous

Le paquet d’installation le fait pendant son exécution, sauf si vous avez décoché Outil en ligne de commande dans son volet Personnaliser. Cependant, macOS interdit à une app en cours d’exécution d’écrire dans /usr/local/bin ; un Zephyr glissé depuis une image disque — ou installé sans ce choix — peut seulement vous montrer la commande et vous laisser l’exécuter une fois vous-même.

  1. Dans les réglages de Zephyr, faites défiler jusqu’à Outil en ligne de commande, puis cliquez sur Copier.

  2. Collez la commande dans le Terminal et appuyez sur Retour.

Zephyr n’a pas besoin d’être ouvert, et vous ne le faites qu’une fois par copie de l’app. Si le volet indique Installé dans /usr/local/bin et ne propose aucune commande, il n’y a rien à faire.

Si le Terminal ne crée pas le lien

La commande commence par sudo, qui pose deux conditions.

  • Il demande un mot de passe. Saisissez le mot de passe de votre session — rien ne s’affiche pendant la saisie, c’est normal — puis appuyez sur Retour.

  • Votre compte doit être administrateur. Un compte standard ne peut pas écrire à cet endroit. Vérifiez dans Réglages Système > Utilisateurs et groupes, ou demandez à la personne qui administre le Mac.

Si le Terminal affiche no such file or directory, c’est que le dossier lui-même n’existe pas. Exécutez d’abord sudo mkdir -p /usr/local/bin, puis la commande que Zephyr vous a montrée.

Si Zephyr indique que l’outil n’est pas inclus

Deux versions affichent ce message, pour des raisons différentes.

  • La version App Store. L’App Store n’autorise pas une app à installer quoi que ce soit dans votre PATH ; elle est donc livrée sans l’outil, et le volet l’indique. La version téléchargeable se trouve sur zephyrmac.app — consultez Choisir entre les deux versions de Zephyr.

  • Une version qui n’inclut tout simplement pas l’outil. Téléchargez de nouveau Zephyr depuis le site du projet.

Si le shell ne trouve pas zephyr

Le lien est installé, mais votre shell ne cherche pas à cet endroit.

  1. Ouvrez une nouvelle fenêtre du Terminal. Un shell déjà ouvert ne prend jamais en compte une nouvelle commande.

  2. Exécutez echo $PATH et vérifiez que /usr/local/bin y figure.

  3. Si ce n’est pas le cas, ajoutez-le dans le fichier de démarrage de votre shell — ~/.zshrc pour zsh.

Remarque : Si vous déplacez Zephyr.app ailleurs, le lien pointe toujours vers l’ancien emplacement. Copiez de nouveau la commande depuis les réglages de Zephyr et exécutez-la : elle indique le nouvel emplacement et remplace l’ancien lien.

Si l’outil ne parvient pas à s’authentifier

zephyr conserve ses identifiants séparément de l’app ; un compte associé par l’app est donc un compte que l’outil peut lister, mais au nom duquel il ne peut pas agir. Exécutez une fois zephyr auth link pour l’outil. Le code de sortie 69 signifie qu’aucun compte n’est associé, ce qui permet à un script de faire la différence avec un véritable échec.
