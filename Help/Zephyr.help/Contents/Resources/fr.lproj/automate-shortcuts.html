Utiliser Zephyr dans un raccourci

Zephyr ajoute des actions à l’app Raccourcis, afin que vous puissiez suspendre la synchronisation, envoyer un fichier vers Dropbox ou obtenir un lien partagé comme une étape d’un ensemble plus vaste. Les deux versions de Zephyr les proposent.

Ajouter une action Zephyr à un raccourci

  1. Ouvrez l’app Raccourcis, puis cliquez sur le bouton d’ajout dans la barre d’outils pour créer un nouveau raccourci.

  2. Dans la liste d’actions à droite, saisissez Zephyr dans le champ de recherche.

  3. Double-cliquez sur l’action de votre choix. Elle apparaît dans le raccourci.

  4. Renseignez ce que l’action demande — un fichier, un dossier, un compte — puis cliquez sur le bouton d’exécution pour l’essayer.

Voici les actions que Zephyr ajoute :

  • Suspendre ou reprendre la synchronisation arrête ou relance la synchronisation de tous les comptes, comme Suspendre la synchronisation dans le panneau de la barre des menus.

  • Masquer les notifications de Zephyr masque toutes les notifications pendant 30 minutes, une heure ou huit heures, ou met fin plus tôt à un masquage. La synchronisation se poursuit.

  • Obtenir l’état de la synchronisation indique combien de fichiers et de dossiers Zephyr a indexés et combien d’éléments n’ont pas pu être synchronisés.

  • Envoyer vers Dropbox envoie un fichier vers un dossier que vous choisissez.

  • Obtenir le lien partagé Dropbox renvoie un lien vers un fichier ou un dossier, en créant un s’il n’en a pas déjà un. Faites-la suivre de Copier dans le presse-papiers pour y placer le lien.

  • Restaurer un fichier Dropbox remet un fichier dans l’une des versions conservées par Dropbox. Elle demande confirmation avant de le faire.

Les champs de fichier et de dossier effectuent leur recherche dans l’index de Zephyr plutôt que sur votre disque ; un dossier dont rien n’a jamais été téléchargé est donc proposé exactement comme un dossier déjà présent.

Exécuter une action sans créer de raccourci

Suspendre la synchronisation, Masquer les notifications et État de la synchronisation sont aussi proposées séparément.

  1. Appuyez sur Commande-Espace pour ouvrir Spotlight.

  2. Saisissez le nom de l’action, par exemple Suspendre la synchronisation.

  3. Appuyez sur Retour.

Vous pouvez aussi les demander à Siri, en disant par exemple « Suspendre la synchronisation dans Zephyr ». Zephyr n’a pas besoin d’être ouvert : il démarre en arrière-plan, fait le travail et ne passe pas au premier plan.

Si une action indique qu’aucun compte n’est associé

Les raccourcis agissent au nom des comptes que vous avez associés dans l’app Zephyr. L’outil en ligne de commande zephyr conserve ses propres identifiants, séparés ; un compte que vous avez associé uniquement en exécutant zephyr auth link n’est donc pas un compte qu’un raccourci peut utiliser.

  1. Cliquez sur Zephyr dans la barre des menus, puis sur Gérer les comptes…

  2. Cliquez sur Associer un compte Dropbox… dans la barre d’outils, puis associez-y le compte.

Lorsque plusieurs comptes sont associés, les actions qui accèdent à un Dropbox demandent lequel utiliser. Avec un seul compte, elles l’utilisent sans rien demander.
