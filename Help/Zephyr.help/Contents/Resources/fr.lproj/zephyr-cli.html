Installer l’outil en ligne de commande zephyr

La version téléchargeable de Zephyr inclut un outil en ligne de commande. Il lit les mêmes comptes et le même index que l’app ; il peut donc lister un dossier dont rien n’a jamais été téléchargé, sans toucher au réseau.

L’installer

Si vous avez installé Zephyr avec le paquet d’installation et laissé l’option Outil en ligne de commande activée, l’outil se trouve déjà dans votre PATH — l’installateur crée le lien pendant son exécution. Ouvrez une fenêtre du Terminal et exécutez zephyr --help. Les réglages de Zephyr l’indiquent aussi : sous Outil en ligne de commande, vous lisez Installé dans /usr/local/bin.

Si vous avez désactivé ce choix dans l’installateur, ou si vous avez installé Zephyr en le faisant glisser depuis une image disque, personne n’a créé le lien. macOS ne permet pas à Zephyr d’ajouter quoi que ce soit à votre PATH lui-même ; Zephyr vous montre donc la commande qui le fait.

  1. Cliquez sur Zephyr dans la barre des menus, puis sur Réglages…

  2. Faites défiler jusqu’à Outil en ligne de commande, puis cliquez sur Copier.

  3. Dans le Terminal, collez la commande et appuyez sur Retour.

    Elle lie l’outil dans /usr/local/bin. sudo vous demande votre mot de passe, et le compte avec lequel vous êtes connecté doit être administrateur.

  4. Ouvrez une nouvelle fenêtre du Terminal et exécutez zephyr --help.

Remarque : La version App Store n’inclut pas l’outil, et le volet l’indique. L’App Store n’autorise pas une app à ajouter quoi que ce soit à votre PATH. Pour utiliser l’outil, installez la version téléchargeable depuis zephyrmac.app — consultez Choisir entre les deux versions de Zephyr, qui explique comment passer de l’une à l’autre sans perdre votre emplacement dans le Finder.

Associer un compte pour l’outil

L’outil conserve ses identifiants dans votre trousseau de session, séparément de ceux de l’app. Il peut voir un compte associé par l’app, mais il ne peut pas agir au nom d’un compte qu’il n’a pas associé lui-même.

  1. Dans le Terminal, exécutez zephyr auth link

    Il affiche une URL d’autorisation et l’ouvre dans votre navigateur.

  2. Autorisez l’accès sur la page de Dropbox, puis copiez le code d’autorisation que Dropbox vous montre.

  3. Revenez au Terminal, collez le code après Enter the authorization code shown by Dropbox:, puis appuyez sur Retour.

zephyr auth list indique avec quels comptes l’outil peut s’authentifier.

Ce qu’il sait faire

zephyr --help dresse la liste complète. En bref : ls, get, put, rm, mkdir et mv pour les fichiers ; revs, restore et diff pour les versions antérieures d’un fichier ; sharelink pour les liens partagés ; find pour chercher un élément par son nom n’importe où dans votre Dropbox, y compris les fichiers qui ne sont pas sur ce Mac ; et status, filestatus et history pour ce que Zephyr sait.

Cinq autres sont les équivalents dans le Terminal de réglages pour lesquels il faudrait sinon ouvrir l’app : bandwidth-limit définit les débits d’envoi, de téléchargement et des réseaux facturés à l’usage ; ignored liste ce que vous avez exclu de la synchronisation ; keep-downloaded liste ce que vous avez conservé sur ce Mac ; notify masque les notifications ; et rebuild-index reconstruit l’index d’un compte. log lit le journal récent de Zephyr, et gui ouvre l’app.

Les commandes agissent sur l’unique compte associé, sauf si vous passez --account. bandwidth-limit, notify, log et gui n’acceptent pas du tout --account, car aucune ne dépend d’un compte en particulier. Treize commandes acceptent aussi --json.

Remarque : watch est une commande de diagnostic, et non un moyen de tenir un compte à jour. C’est Zephyr lui-même qui surveille les modifications dans Dropbox — consultez Laisser Zephyr s’exécuter en arrière-plan.

Ajouter la complétion du shell

zephyr --generate-completion-script écrit un script de complétion pour zsh, bash ou fish. Pour zsh :

  1. Exécutez mkdir -p ~/.zsh/completions

  2. Exécutez zephyr --generate-completion-script zsh > ~/.zsh/completions/_zephyr

  3. Ajoutez fpath=(~/.zsh/completions $fpath) à ~/.zshrc, au-dessus de la ligne compinit, puis ouvrez une nouvelle fenêtre du Terminal.

Les chemins Dropbox sont complétés à partir de l’index de Zephyr, un dossier par appui sur Tab ; un dossier dont rien n’a été téléchargé se complète donc exactement comme un dossier déjà présent.
