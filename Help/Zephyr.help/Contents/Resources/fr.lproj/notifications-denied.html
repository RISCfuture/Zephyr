Si vous ne voyez pas les notifications de Zephyr

Trois éléments distincts peuvent rendre Zephyr silencieux ; mieux vaut les écarter dans cet ordre.

Vérifier que macOS les autorise

  1. Choisissez le menu Pomme > Réglages Système, puis cliquez sur Notifications.

    Ouvrir Notifications pour moi

  2. Repérez Zephyr, puis activez Autoriser les notifications.

Si vous avez refusé la première demande de Zephyr, c’est le seul endroit où modifier cette réponse — macOS n’affiche pas la demande une seconde fois, et Zephyr ne peut pas la provoquer.

Vérifier le niveau propre à Zephyr

  1. Cliquez sur Zephyr dans la barre des menus, puis sur Réglages…

  2. Sous Notifications, vérifiez Notifier à propos de.

Avec Erreurs uniquement, une modification de fichier ordinaire ne déclenche pas de notification. Avec Aucune, rien n’en déclenche. Consultez Choisir les notifications que Zephyr affiche.

Vérifier si les notifications sont masquées

Cliquez sur Zephyr dans la barre des menus. Si un masquage est en cours, la ligne indique Masquées jusqu’à suivi de l’heure de fin. Cliquez sur Reprendre pour y mettre fin tout de suite.

Rien n’est perdu à cause d’un masquage : ce qu’il a masqué fait l’objet d’une notification dès qu’il prend fin.

Remarque : Un mode de concentration de macOS peut retenir les notifications de toutes les apps à la fois. Vérifiez la concentration active dans le Centre de contrôle avant de conclure que Zephyr est en cause.
